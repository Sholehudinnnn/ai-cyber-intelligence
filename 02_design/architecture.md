# Rancangan
Pengguna memasukkan indikator -> Flask memvalidasi -> aturan demo menghitung tingkat risiko -> dashboard menampilkan alasan dan saran.
OpenAI Agent bersifat opsional untuk menjelaskan hasil. Pada tahap berikutnya, aturan demo dapat diganti/ditambah dengan model ML yang telah dilatih dan dievaluasi.
